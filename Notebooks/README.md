# 🏠 Real Estate Price Prediction

A Machine Learning based Real Estate Price Prediction system built with **Python, Django REST Framework, HTML, CSS, JavaScript**, and **Power BI**.

## Features

- House price prediction
- Django REST API
- Prediction history
- Responsive UI
- Machine Learning model
- Power BI Dashboard
- Docker Ready

## Tech Stack

- Python
- Django
- Django REST Framework
- Scikit-learn
- HTML
- CSS
- JavaScript
- SQLite
- Power BI
